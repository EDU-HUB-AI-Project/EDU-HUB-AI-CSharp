# 스마트 EDU-HUB AI 키오스크 관리자 시스템 개발 Project
>  키오스크 시스템 관리자 전용 프로그램

## 📌 프로젝트 개요
| 항목 | 내용 |
|---|---|
| 사업명 | 스마트 EDU-HUB AI 키오스크 관리자 시스템 개발 Project(2차) |
| 대상 | 한국산업안전보건교육원 교육원 관리자 |
| 해상도 | 1080 × 1920px 세로형 터치 키오스크 |
| 역할 | 관리자 프그램 |
| 포트 | 8080 |


### 목적

1. 1차 키오스크 시스템(사용자 화면)과 연계하는 관리자 백오피스 구축
2. 교육생, 출석, 생활관 배정 등 핵심 데이터의 통합 관리 환경 제공
3. 키오스크에 노출되는 콘텐츠(시설, 메뉴, 교통, 강의실 배치도)의 실시간 등록, 수정
4. 이용 현황 통계 및 대시보드를 통한 운영 효율성 증대




---



## 🏗️ 시스템 아키텍처

| 관리자 프로그램 (C# Winform) | Server B (API 서버, Java) | Server A (DB 연동 서버, Java) |
|:---:|:---:|:---:|
| 운영자 PC | RESTful API 제공 | DB 연동 |
| ← REST API 호출 | ← 내부 API 호출 | 데이터 처리 |

- 본 관리자 시스템은 1차 시스템의 API 서버를 통해 데이터에 접근함
- DB 접근을 직접 배체하여 데이터 일관성 및 보안성 확보

## ✅ 주요 요구 기능

## 👥 1. 교육생 관리

### 가. 교육생 정보 관리
- **교육생 기본 관리**: 등록 / 수정 / 삭제 / 일괄 등록 (Excel 업로드 지원)
- **필수 정보 관리**: 이름, 생년월일, 연락처, 소속 과정, 생활관 신청 여부 등
- **검색 및 필터링**: 교육 기수별, 과정별 맞춤형 조회 기능 제공

### 나. 출석 현황 관리
- **출석 현황 조회**: 일자별 / 과정별 조회 (키오스크 명찰 출력 시 자동 갱신된 데이터 실시간 표시)
- **수동 출석 관리**: 지각, 결석, 조퇴 등 사유 입력 및 상태 변경 기능
- **데이터 내보내기**: 출석 현황 Excel 다운로드 지원

### 다. 생활관 배정 관리
- **배정 현황 조회**: 생활관 호실별 잔여 인원 및 정원 파악
- **호실 관리**: 수동 배정 조정 및 입실/퇴실 처리
- **실시간 연동**: 배정 정원 변경 시 키오스크 데이터 즉시 반영

---

## 🏢 2. 콘텐츠 관리

### 가. 시설 정보 관리
- **구내식당 식단 관리**: 일일 메뉴 등록 및 수정 (조식, 중식, 석식 구분)
- **시설 위치 안내**: 교내 주요 시설(흡연장소, 휴게실, 의무실 등) 위치 정보 관리
- **미디어 업로드**: 시설 관련 이미지 및 지도 업로드 기능

### 나. 강의실 배치도 관리
- **배치도 관리**: 교육 과정별 강의실 배치도 이미지 등록 및 수정 기능

### 다. 교통 정보 관리
- **대중교통 안내**: KTX 및 시외버스 시간표 정보 등록 / 수정
- **셔틀버스 관리**: 셔틀버스 운행 정보 및 노선 관리
- **실시간 연동**: 교통 정보 변경사항 등록 시 키오스크에 즉시 반영

---

## 📊 3. 대시보드 관리

### 가. 메인 대시보드
- **실시간 출석 현황**: 당일 출석 인원 및 미출석 인원 한눈에 파악
- **생활관 배정 현황**: 전체 정원 대비 현재 입실 인원 시각화
- **키오스크 트래픽**: 시간대별 명찰 발급 건수 등 이용 통계 제공

##  프로젝트 구조
```bash
EDU_HUB AI/
├── Config/         # 설정 관련 클래스

├── Controller/     # 비즈니스 로직 및 이벤트 처리

├── Model/          # 데이터 모델 및 객체

├── Service/        # API 통신 등 핵심 서비스 로직

├── Util/           # 공통 유틸리티 및 헬퍼 클래스

├── View/           # WinForm 화면 (UI)

├── config.json     # 프로젝트 환경 설정 파일

└── Program.cs      # 애플리케이션 진입점 (Main)
```
